# 🏦 Insurance Portal UI Clone (ICICI Lombard Replica)

## 📌 Overview

The **Insurance Portal UI Clone (ICICI Lombard Replica)** is a frontend-focused project that recreates the **Motor Insurance section** of the ICICI Lombard website.  

This project has been developed **strictly for educational and portfolio purposes**, with the intent to demonstrate strong capabilities in **modern frontend development, responsive UI design, and structured component-based architecture**.

The application focuses on visually and functionally replicating a **real-world financial insurance platform**, emphasizing user experience, layout precision, and scalable UI patterns commonly used in enterprise-grade applications.

### 🎯 Project Goals

- Recreate the **visual layout and user flow** of a large-scale insurance platform  
- Demonstrate **component-based UI architecture**  
- Implement **responsive designs** across devices  
- Practice structuring **complex forms and insurance product flows**

## 🔧 Installation & Usage

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/insurance-portal-ui-clone.git
```

### 2️⃣ Navigate to the Project Directory

```bash
cd insurance-portal-ui-clone
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Development Server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173/
```
